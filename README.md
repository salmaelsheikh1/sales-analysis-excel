# Sales Analysis & Excel Dashboard

## Project Overview
An end-to-end sales data analysis project built using Microsoft Excel.

## Tools & Skills
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Slicers and dashboard design

## Data Cleaning
- Inspected data quality and column profiles.
- Checked for missing values and errors.
- Investigated repeated Order IDs to distinguish valid order lines from duplicate records.

## Business Questions
- What are the total sales and total profit?
- How do sales change over time?
- Which products generate the highest sales?
- Which product categories generate the highest sales?
- Which regions perform best?

## Key Findings
- Total Sales: Approximately 2.33 million.
- Total Profit: Approximately 292.30 thousand.
- Overall Profit Margin: Approximately 12.56%.
